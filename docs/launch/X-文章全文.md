# 我给国际象棋加了一个赛后才打开的秘密

你有没有遇过这种对手：他随手走一步，你盯着棋盘看了很久，最后决定——他一定算到了什么。

当然，也可能他什么都没算到。

我想把这层误会做成一个能玩的东西。所以，我给自己的国际象棋小站「棋间」加了真人联网对战，也加了一个藏在胜负之后的功能：**心声揭晓**。

## 先把第二把椅子放上来

打开棋间，可以直接匹配另一位真人，也可以开房，把链接发给朋友。免注册，选个称呼就能入座。每人五分钟，每步加三秒。刷新能回到原局，断线时的时钟仍会继续。

这是一间小棋室。匹配池暂时没人，就如实等人。你也可以把那把空椅子留给一个具体的朋友。

有了另一个人，一步棋才有了真正的回应。

## 落子之前，封存一个念头

轮到你走时，可以先选一句心声：

**算过了。虚张声势。我也没底。**

然后落子。那句话随着这一手被封存，对手在对局中看不到。你可以不选，保持神秘也是棋风。

还可以猜猜对面上一手的心声。你觉得那是准备好的陷阱，还是他把紧张藏得比较好？

没有摄像头，没有情绪识别，没有假装看穿你的 AI。这里记录的，只是你自己选下的那句话。

## 下完，才知道刚才发生了什么

在一盘测试棋里，白方留下「我也没底」。黑方猜的是「算过了」，自己随后也留下「我也没底」。

结束后，两边才看到：原来那份胸有成竹，是彼此脑补出来的。

系统为这局写下一句话：**原来，我们都在硬撑。**

你会看到具体是哪一步，自己封存了什么，对面又猜了什么，还能保存成一张心声卡片。卡片留下的是这盘棋的细节，不是另一份需要炫耀的等级分。

有人想分享将死的瞬间，也有人更想分享：「你刚才居然是在唬我？」我更期待后面那句话。

## 我说“像爵士”，说的是参与的感觉

我最初想要的快乐，像在现场听爵士、跟着节奏跳舞：你做一个动作，世界接住它，又还给你一点意外。

那个比喻曾让项目长出一个真的爵士功能。走一步，钢琴、贝斯和鼓就回应一句。它很有趣，我把它留了下来。

接着，我做了「平行棋局」：让你无损试走，看同一个起点会展开哪些参考变化，再决定是否把那一步落进原局。

现在，多了「心声揭晓」。前一个功能让自己的选择变得可见，这次，我想让对面的人也变得可见。

两种发现都让我着迷：原来这步妙棋，我也能找到。原来刚才紧张的人，不只有我。

## 值得明天再来的理由

我还没有证据说，这个小功能会让所有人爱上下棋。它是一个认真做出来、可以亲手玩的产品假设。

我想试的 X 因素是：**每盘棋结束后，你带走一点关于另一个人的故事。**

今天遇到的人、他愿意留下的心声、你对他的误判，都不会完全一样。下一盘的惊喜，也许就在最不确定的那一步。

网站里还有中文复盘、个人错题本、平行棋局和每日爵士即兴。可以认真练棋，也可以下完一盘，笑着承认刚才全靠气势。
