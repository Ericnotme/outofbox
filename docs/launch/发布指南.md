# 棋间发布包 · 2026-09-25

## 推荐发布顺序

1. 上传 `knight-room-launch.mp4`，配 `X-首帖与串文.md` 中的中文首帖。视频有内嵌字幕，静音可看懂。
2. 首条回复放 GitHub 入口与简短 Star 邀请。主帖保留直接试玩链接，减少寻找入口的步骤。代码链接放回复是内容分工，不是“外链必被降权”的判断。
3. 用 `cover.png` 作封面，正文粘贴 `X-文章全文.md`。有 Articles 入口就用；否则发 Premium 长帖。
4. 首帖和文章分开发布，选你能回应读者、在大厅陪大家下棋的时间。冷启动时，有真人能匹配比一个“最佳发布时间”更有用。
5. 后续讲一次真实对局的故事，配双方愿意分享的心声卡。不要连续复制同一段广告。

这是供你审阅、上传的素材包，没有自动发布到 X。

## X：公开事实与编辑判断

X 会预测阅读、观看、回复、分享等动作，也考虑不感兴趣、屏蔽、举报等负反馈。权重乘的是预测概率，不是原始互动次数，配置还会变化。[官方算法仓库](https://github.com/xai-org/x-algorithm)

因此本次采用的**编辑判断**是：前几秒给出“对手似乎算过，其实都没底”的反差，随后演示具体棋局，最后问一个相关问题。目标是让合适的人看懂并回应，不保证推荐量。没有采用固定涨粉公式、互刷互动或虚假用户数据。

Premium 长帖支持最多 25,000 字符。[Premium 帮助](https://help.x.com/en/using-x/x-premium) 当前 Articles 专页列明 Premium、Premium+ 及相关商业订阅可发表文章，支持图片、视频与链接，以账户实际入口为准。[Articles 帮助](https://help.x.com/en/using-x/articles)

视频采用短时长 H.264 MP4，远低于普通与 Premium 的时长门槛。官方页面对超长视频上限的描述存在差异，本包不依赖这些边界。[视频帮助](https://help.x.com/en/using-x/x-videos)

本次 README 已按此组织：封面、直接试玩、特色体验、运行步骤、能力边界、轻量 Star 邀请。GitHub Trending 没有可承诺的完整排序公式，本包不承诺排名。

准确 Topics：`chess` `multiplayer` `javascript` `cloudflare-workers` `sqlite` `browser-game` `game-design` `chess-analysis`。如果连接无法修改设置，可粘贴到仓库右侧 About 齿轮。不要加不存在的 `websocket`、`ai-agent` 标签。

## 判断效果

记录曝光、视频观看、有效回复，以及 GitHub 的访问和 Star 变化。UTM 只区分入口；网站没有因此新增用户追踪，不能自动统计来源转化。

更有价值的问题：是否等到对手、是否完成一局、是否理解心声保密、揭晓后是否想邀请朋友。用反馈迭代，不用一条帖子的成绩证明或否定创意。
